How the route stays bounded

CodeCanopy uses an ownership tree for authority and an artifact dependency DAG for execution order.

  1. Leaf test

    Define the smallest independently verifiable outcome, then work backward only to the dependencies needed to prove it.

  2. Critical frontier

    Expand only the minimum ready work that can advance the next proof; sibling work is not a reason to widen scope.

  3. Parent acceptance

    Accept a parent only after its required artifacts and evidence are present. The root retains integration and the final verdict.

Configuration is a planning ceiling

An optional project-root .codecanopy.toml can lower or tune these v0.2 defaults. It cannot grant authority.

[codecanopy]
max_depth = 3
max_children_per_node = 3
max_total_nodes = 9
max_parallel = 3
root_reserve_percent = 35
retry_limit = 1

Safety clearance

CodeCanopy guides agent behavior; Codex and its sandbox enforce model availability, concurrency, worktree isolation, permissions, and approvals. Delegation never expands your authority.
